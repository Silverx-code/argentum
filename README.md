# Argentum — Firebase Auth Setup Guide

Complete step-by-step from zero to a running Flutter app with Firebase Auth,
Google Sign-In, email verification, and Firebase Storage wired up.

---

## Step 1 — Prerequisites

Make sure these are installed:

```bash
# Flutter (3.x+)
flutter --version

# Firebase CLI
npm install -g firebase-tools
firebase --version

# FlutterFire CLI
dart pub global activate flutterfire_cli
flutterfire --version
```

---

## Step 2 — Create Firebase Project

1. Go to https://console.firebase.google.com
2. Click **Add project** → Name it `argentum-ai`
3. Disable Google Analytics (not needed for MVP)
4. Click **Create project**

---

## Step 3 — Enable Authentication

In Firebase Console → **Authentication** → **Sign-in method**:

| Provider        | Action                                      |
|-----------------|---------------------------------------------|
| Email/Password  | Enable ✓                                    |
| Google          | Enable ✓ → set support email               |

---

## Step 4 — Create Firestore Database

1. Firebase Console → **Firestore Database** → **Create database**
2. Choose **Production mode**
3. Pick a region close to Nigeria: `europe-west1` (Belgium) or `us-central1`
4. After creation, go to **Rules** tab and paste contents of `firestore.rules`
5. Click **Publish**

---

## Step 5 — Create Firebase Storage

1. Firebase Console → **Storage** → **Get started**
2. Start in **Production mode**
3. Same region as Firestore
4. Go to **Rules** tab, paste contents of `storage.rules`
5. Click **Publish**

---

## Step 6 — Connect Flutter App (FlutterFire CLI)

Run this in your project root:

```bash
firebase login

flutterfire configure \
  --project=argentum-ai \
  --platforms=android,ios
```

This will:
- Auto-generate `lib/firebase_options.dart` ← replaces the placeholder
- Download `android/app/google-services.json`
- Download `ios/Runner/GoogleService-Info.plist`

---

## Step 7 — Android: SHA-1 Certificate for Google Sign-In

Google Sign-In **requires** your SHA-1 key registered in Firebase.

```bash
# Get debug SHA-1
cd android
./gradlew signingReport

# Copy the SHA1 from "Variant: debug" section
```

Then:
1. Firebase Console → **Project Settings** → **Your apps** → Android app
2. **Add fingerprint** → paste SHA-1
3. Download the updated `google-services.json` and replace the existing one

## Auth Flow Summary

```
App Launch
    │
    ▼
AuthGate (StreamBuilder on authStateChanges)
    │
    ├── null user ──────────────────────────► SignInScreen
    │                                              │
    │                                    ┌─────────┴─────────┐
    │                                    │                   │
    │                               Email/Pass          Google OAuth
    │                                    │                   │
    │                                    └────────┬──────────┘
    │                                             │
    │                                        AuthService
    │                                             │
    │                                    Firebase Auth SDK
    │                                             │
    ├── user + emailVerified=false ───────► EmailVerifyScreen
    │                                       (polls every 3s)
    │
    └── user + emailVerified=true ────────► HomeScreen
```

## Common Issues

### Google Sign-In crashes on Android
→ SHA-1 not registered. See Step 7.

### `FirebaseApp not initialized`
→ `firebase_options.dart` is still the placeholder. Run `flutterfire configure`.

### `CONFIGURATION_NOT_FOUND`
→ `google-services.json` is missing or in wrong folder (`android/app/`, not `android/`).

### Email verification not detected
→ The poll timer checks every 3 seconds. Make sure to call `user.reload()` before checking `emailVerified` — Firebase caches the old value.

### Firestore permission denied
→ Check that `firestore.rules` is deployed and `emailVerified` is true for the user.

## Environment Variables (Backend — for later)

When wiring to FastAPI backend, pass the Firebase UID as a Bearer token:

```dart
// Get Firebase ID token (refreshes automatically)
final token = await FirebaseAuth.instance.currentUser?.getIdToken();

// Send to backend
headers: {
  'Authorization': 'Bearer $token',
  'Content-Type':  'application/json',
}
```

Backend verifies with:
```python
# Python / FastAPI
from firebase_admin import auth
decoded = auth.verify_id_token(token)
uid = decoded['uid']
```
